#### Что реализовано

##### Flexbox

- Горизонтальное адаптивное меню навигации
- Карточки идей стартапов (4 шт.) в ряд
- Карточки: 1 / 2 / 4 колонки в зависимости от экрана

##### CSS Grid

- Сетка ключевых метрик (MAU, LTV, CAC — 3 блока)
- Grid: 1 / 2 / 3 колонки в зависимости от экрана

##### Семантика и теги

- `<meter>` — для визуализации метрик
- `<data value="...">` — для числовых значений
- `<article>` — для каждой карточки идеи и метрики
- `<section>` — для блоков «Идеи» и «Метрики»
- `<nav>` — для навигационного меню

##### Адаптивность

- Медиа-запрос для планшетов (max-width: 768px)
- Медиа-запрос для мобильных (max-width: 480px)
- Отсутствие горизонтальной прокрутки на любых экранах
